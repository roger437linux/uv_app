✅ 1. Inicializar o Git na aplicação local

git init
git branch -M main
git status

Onde:
- git init: cria o repositório Git local, caso ainda não exista
- git branch -M main: define o nome da branch atual como main
- git status: mostra os arquivos que serão considerados pelo Git


✅ 2. Configure seu nome e e-mail

git config --global user.name "Seu Nome"
git config --global user.email "seu-email@example.com"


✅ 3. Adicione os arquivos e faça o primeiro commit

git add .
git commit -m "Initial commit"

Obs.: Commit registra uma versão do seu código no histórico local


✅ 4. Criar repositório no github

URL HTTPS:
    https://github.com/roger437linux/uv_app.git


✅ 5. Conectar o projeto local ao GitHub

git remote add origin https://github.com/roger437linux/uv_app.git
git remote -v


✅ 6. Enviar projeto

git push -u origin main


✅ 7. Daqui em diante

git add .
git commit -m "Describe your changes"
git push


✅ 8. Se alterações no GitHub e quiser trazê-las para o computador

git pull


✅ 9. Em outra máquina

git clone https://github.com/USER/REPO.git
cd REPO
uv sync

uv run tux
